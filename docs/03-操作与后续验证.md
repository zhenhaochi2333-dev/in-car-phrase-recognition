# 操作说明与后续验证计划

本文件保留完整实验验收计划。已经完成的本机联调与按钮交互检查见《06-实机与交互验证》，不等于以下验收项目全部通过。

## 使用流程

1. 启动应用，处于待机，自动播报关闭。
2. 默认使用“实验口令”模式，预置 `down、go、left、no、off、on、right、stop、up、yes`。静音和未知属于识别状态，不作为可朗读短语。在“识别工作台”切换到自定义模式后，使用“短语库”内启用的短语；模式和短语修改会保存供下次启动使用。
3. 进入“短语库”搜索、添加或编辑短语，勾选启用，保存。可用 JSON 导入导出整个列表。编辑框中“手动设置发音”用于修正多音字或英文词典外词，所填写的词元必须来自模型词表。
4. 必要时点击刷新设备并选择真正的麦克风。设备索引会随 Windows 设备变化而变化；本机使用 Realtek 麦克风阵列，不要选择立体声混音。
5. 点击开始监听。初始化在后台运行，模型加载完成后才打开输入设备。
6. 说出一个短语，观察文字。开启自动播报后，电脑用合成声音读出文字。此时请等播报结束再说下一句。
7. 点击停止结束收音和播报，可导出会话记录。

修改前先到识别工作台点击停止，等待收音和播报结束；此后短语库和设置页解除锁定。保存后手动开始监听，使用新配置，历史记录与自动播报选择保留。新增或修改成功会选中对应短语，输入无效时弹窗保留并显示原因。

无声音产生的操作包括编辑配置、保存、导出、编译、静态检查；设备刷新会查询音频设备但不会播放声音。界面内“检查发音配置”执行文本转换，不运行音频识别。

## 自定义模式验收

- 添加新短语后不重新训练，验证保存、重启恢复、启停、删除、词元修正。
- 测试中英文、相似发音、很短的口令、未配置语句，分别记录命中、漏检和误触发。
- 在一段连续声音里记录误触发次数/小时、漏检率和重复触发；不能直接套用孤立词分类准确率。
- 检查静音状态与“检测到声音但没有命中”的未知状态；当前有声段门控基于 RMS，环境噪声也可能超过阈值，并不具有完整语音 VAD 的能力。
- 模型检测的是设定短语出现与否，不理解否定、讽刺或控制意图；识别成功不表示真的控制了汽车设备。

## 播报与生命周期验收

- 仅最终 command 事件送入 TTS，静音、未知、错误、设置保存不播报。
- 用屏幕文字与播报内容核对，证明输出由文字合成；原始录音没有输出通路。
- 自动播报默认关闭；手动重读只针对已选中的命令记录。
- 播报期间识别暂停，结束清空缓存后恢复；观察余音能否造成重复命中。
- 在加载、收音、推理和播报各阶段点击停止、关闭窗口，确认设备释放且无迟到播报。
- 检查麦克风断开、权限拒绝、缺失声音引擎、模型文件缺失、配置损坏等错误。
- 分别测量识别延迟和播报启动延迟；长句完整播报时长由文字和语速决定。

## 用电脑本机硬件采集与离线实验评估

`scripts/record_dataset.py` 只在用户主动运行并逐条按 Enter 后才打开本机麦克风；录得的 WAV 和 JSON 清单都只保存在项目目录，不会上传。`scripts/evaluate_dataset.py` 不访问音频设备，但会真正运行 C++ 识别核心，因此属于功能评测而不是静态检查。

先列出可用输入设备：

```powershell
.\.venv\Scripts\python.exe scripts/record_dataset.py --list-devices
```

选择真正的麦克风后，每类至少录 3 条，并按说话人和环境分组。例如：

```powershell
.\.venv\Scripts\python.exe scripts/record_dataset.py --label yes --count 3 --speaker student-a --condition clean --device 设备编号
```

对 `_silence_` 录安静片段；对 `_unknown_` 录不是十个课程命令的词，例如 `straight`。后者应作为未知类统计，不应当被当作漏识别的课程口令。

准备 JSON 清单，路径相对清单所在目录：

```json
[
  {"path": "audio/yes_001.wav", "label": "yes"},
  {"path": "audio/silence_001.wav", "label": "_silence_"}
]
```

音频必须为 16 kHz、单声道、16 位 PCM WAV，时长大于零且不超过 1 s；短音频尾部补零。清单需覆盖全部 12 类，调参集与最终测试集分开。样例名称只是说明，不是已经存在或已经测过的样本。

收齐各类样本后执行：

```powershell
.\.venv\Scripts\python.exe scripts/evaluate_dataset.py .\data\evaluation_samples\dataset.json --require-all-labels
```

每次运行会创建独立的 `exports/evaluation-时间戳/` 结果目录，输出逐文件预测、计算耗时、混淆矩阵、每类覆盖数、总准确率、每类 Recall/Precision/F1，以及按说话人和环境的分组结果。该脚本评估孤立音频分类，不评估实时门控、事件重复、TTS 或端到端延迟；不能用模型单次推理耗时代替课程要求的端到端响应速度。

## 本阶段不作出的结论

界面交互及基础识别播报已实测，完整统计验收仍未完成。课程参数与官方模型的数值等价性、所有自定义短语的准确性、低于 1 s 的端到端延迟以及复杂噪声下的回声抑制，均需各自的验证证据。
