## 实际改进

| 部分 | 原版本 | 本次采用 |
| --- | --- | --- |
| 评测样本准备 | 需要自行准备符合格式的 WAV 和清单 | 增加明确按 Enter 后采集的一秒录音工具，支持设备、说话人、环境标记以及 RMS/峰值记录 |
| 离线评测 | 基础准确率、混淆矩阵和时间统计 | 增加完整 12 类覆盖检查、逐类 Recall/Precision/F1、说话人与环境分组、预热、独立输出目录及 Markdown 报告 |
| 构建 | 优先使用 PATH 中的 g++，否则依赖 CMake | 跳过不兼容的旧版或 32 位 MinGW，寻找 MSVC，保留 CMake 后备；先编译候选 DLL 再替换 |
| 启动 | 默认解释器和较少的环境提示 | 明确检查 Python 3.11+，支持指定解释器；增加双击启动入口 |
| 界面 | 输入状态提示有限 | 说明固定 12 类与自定义模式的区别；提示混音设备；用待机文字表示静音，不覆盖已识别结果或触发 TTS |

本次没有改变课程 Log-Mel/BC-ResNet 推理实现、自定义识别逻辑、阈值或模型参数。归一化换行后，包内 `native/core.cpp`、`native/core.h`、`engines.py`、`audio.py`、`workers.py` 与原版本无实质差异；ONNX 模型、词典、词元和课程 `table.c` 与本地文件的哈希一致。很多表面上的文件差异只是换行格式变化，没有必要覆盖。

原来的交互约束继续生效：监听、播报及停止处理中锁定编辑；完全停止后才能添加或修改短语。当前用户保存的词语、设备和参数配置，以及未提交的 `.vscode/settings.json`，保持原样。

## 合并时修正的问题

- 某类别有真实样本但全部识别错误时，F1 应为 0，不能显示为缺失值；只有真实和预测样本均为零时才为未定义。
- 清单拒绝重复文件路径、重复 ID、越出清单目录的路径和非固定类别；读取 WAV 时拒绝被截断的数据。
- 评测报告新增样本清单和实际使用的 DLL 的 SHA-256，并记录预热次数，用于追溯评测版本。
- 录音文件写入前拒绝 NaN/Infinity 样本，避免生成无效指标。
- 编译候选 DLL 时检查 PE 文件头、x64 架构和 DLL 标志，检查失败保持原有 DLL；MSVC 使用静态 C/C++ 运行库。
- 混音输入提示使用更明确的中英文名称，识别“立体声混音”，避免仅因名称含 stereo 就警告普通立体声麦克风。
- PowerShell 启动脚本使用 UTF-8 BOM，兼容 Windows PowerShell 读取中文；清理文档中来自其他机器的 Python 路径。
