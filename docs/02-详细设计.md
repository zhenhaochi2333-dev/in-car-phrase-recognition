## 配置和事件

`Phrase`：稳定 ID、原文 text、enabled。播报文字默认严格使用 text，不声称设备已执行命令。短语不允许为空、重复、换行或包含关键词文件的控制符。限定为普通汉字、英文字母、空格与英文撇号，限制总条数与长度。中文多音字可以在模型词元编辑框提供人工修正；高级词元同样需要逐个通过模型词表验证。

`Settings`：模式（experiment/custom）、输入设备索引（-1 为系统默认）、音量与语速、实验阈值、RMS 有声阈值、短语列表。数值加载后验证范围，未知版本或损坏配置报告清晰错误。使用临时文件加 `os.replace` 原子保存；自动播报状态不持久化。

默认实验口令为 `down、go、left、no、off、on、right、stop、up、yes`。自定义触发阈值调整为 0.25，有声电平阈值调整为 0.004；选择依据和本轮暂停测试的边界见《07-英文漏识别调整》。已保存模式和短语按用户配置恢复，不在每次启动时重置。

`RecognitionEvent`：事件类型 command/silence/unknown/status、短语、引擎、时间戳、可空 score、纯处理耗时 ms。处理耗时不能标作端到端响应时间；无人工真实标签时不能显示准确率。

## 启停控制

按用户要求不提供专门的图书馆模式。音频会话由开始监听、手动重读及自动播报选择触发；短语和设置只能在停止监听及播报后修改，保存不会启动音频任务。`AudioPolicy` 管理播报互锁和应用关闭状态。关闭后不能启动音频任务，后台线程不得跨线程操作界面。

不开机自启动、不自动开始监听、不自动播报。所有普通提示用界面文字，不调用系统 beep、MessageBeep 或声音通知。自动播报每次启动默认关闭。

## 采集与调度

- 20 ms PCM 块，目标 16 kHz、单声道 float32，原声不转发到输出设备。
- 先尝试 16 kHz；设备不支持时使用其默认采样率，按连续时间索引转换，避免各块独立重采样的时间漂移。降采样使用十阶 Butterworth IIR 低通与线性插值，滤波器状态跨块保留，在播报结束或输入积压清理后重置。
- PortAudio 回调只复制输入到有界队列，禁止在回调里运行模型、TTS 或 UI 操作。队列溢出直接记录并重置识别状态，避免旧声音长期积压。
- 识别工作线程消费队列。模型初始化在后台完成；停止信号在初始化后和打开设备前再次检查。
- 启动后按当前模式创建引擎，不共享两套特征参数。播报互锁期间丢弃采集块，解除时重建音频段状态和模型流。

## 实验引擎

C ABI：`lab_create` / `lab_destroy` / `lab_predict` / `lab_last_error`。每个句柄独立持有窗口和 Mel 滤波器组，参数只读。输入固定 16000 个 float 样点，输出 12 个 logits 与 12 个 softmax 得分；所有异常在 DLL 内转换为错误码，不越过 C ABI。

前端：16 kHz；480 点周期 Hann 窗；160 点步长；512 点 FFT；40 维 HTK Mel 三角滤波器；功率谱后 `ln(power + 1e-6)`；两端反射补齐；101 帧。原样例的 PCM 除以 32768 的语义由 float 输入规范完成。

网络：入口 5×5 卷积及 BN/ReLU；四阶段块数 2/2/4/4，通道 8/12/16/20，时间空洞率 1/2/4/8；频率子带归一化；广播残差；分类头和全局平均池化。实际参数形状以课程 table.c 为准，部分逐通道参数使用 `[channel][0]` 存储，不能未经验证就替换为官方 PyTorch 权重布局。课程分类头是 5×5，遵循提供参数，不擅自换成论文 5×1。

每 100 ms 用最近 1 s 运行一次；短语事件需连续稳定候选，并满足阈值与再触发间隔。静音或未知不提交 TTS。有声门控用于降低静音误触发，不能代替 12 类网络输出。实测前阈值均只是初始参数。

## 自定义引擎

- 使用官方 `sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20`，CPU 推理。
- 使用本地 `tokens.txt` 与 `en.phone`，中文由 pypinyin 转为 initials/finals，英文使用词典。优先采用当前安装的 sherpa 官方 text2token 实现，在开发时静态检查 API 与依赖。
- 关键词文件用稳定 ID 别名，命中 ID 后映射为用户原文，防止空格和底层 token 影响显示。
- 每次命中调用 reset_stream，避免沿用命中路径。
- 有声段后继续接收约 600 ms 的真实安静输入，给流式解码保留尾部上下文，再结束当前段；若整段没有命中则显示“未匹配到短语”。静音状态与未知事件分开。
- 停止监听后可修改短语、发音与阈值；保存后先校验，下次手动开始时使用。空启用列表允许保存，但不能启动自定义监听。全局阈值为触发控制参数，不显示为分类准确率。
- 第三方原生库在 Windows 上不能可靠读取中文路径，模型运行副本保存在当前用户的英文缓存路径；每次核对模型内容，只复制变化文件。关键词文件按实例生成，加载后清理，避免实例间相互覆盖。

## 语音合成

Windows SAPI 在专用线程里初始化 COM；仅接收最终文字。按内容选择中文/英文系统声音，允许设置语速和音量。使用异步 Speak 并轮询完成事件，取消时 purge。未发现匹配语言的声音时报告错误，不能静默换成不支持该语言的声音。

任何播报前进入音频抑制状态；完成、取消和错误均必须在 finally 里释放状态，并增加约 350 ms 余音等待。手动重播同样遵守应用生命周期和互锁。停止任务时取消当前播报，不积压后续播报队列。

## 界面

中文桌面界面采用左侧导航，分为识别工作台、短语库和设置页。工作台集中显示识别结果、监听控制、输入电平和会话历史。短语库提供搜索、增删改、启停和手动发音；设置页集中展示阈值、音量语速及模型文件状态。监听或播报期间锁定编辑入口并提示先停止。新增和编辑后清空搜索过滤并选中修改项；重复短语或无效词元在弹窗内提示，失败不改变持久化设置。布局和图标样式分别由 `layout.py` 与 `appearance.py` 管理。

`can_edit()` 要求识别和播报对象均已退出，且应用未关闭。点击停止后仍需等待两个线程完成，才恢复编辑入口；保存处理函数同样检查此条件，避免绕过禁用按钮修改运行配置。取消了自动重启监听机制，开始监听只能由用户操作触发。没有选中项目时禁用编辑、删除或朗读，并通过鼠标提示说明原因。

关闭窗口先发出停止和取消信号，等待工作线程退出后销毁。模型加载可能不可立即中断，期间保持窗口可见、按钮禁用并提示正在关闭，避免销毁仍运行的 QThread。
